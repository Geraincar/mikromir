# Микромир: исходники сайта

Сайт собирается в один файл: `index.html` (он же `mikromir.html`), фото костюма встроено внутрь.

## Логика: два цикла
- **Быстрый цикл, 4 раза в секунду.** Камера → трекинг → состояние каждой клетки → условия на костюме.
  Сценарий задаёт правила (риск мутации, сила иммунитета), положение актёра задаёт дозу:
  жар → грозит мутация, холод → клетка гибнет, вибрация → контакт, цвет → состояние.
- **Медленный цикл, на развилках.** Модель каждую секунду сравнивает сводку сцены с ветками базы (процент совпадения),
  но сценарий меняется только на развилке: ИИ предлагает ветку с лучшим совпадением, режиссёр оставляет её или выбирает другую.
  Молчание режиссёра = согласие с ИИ. Внеочередная развилка: другая ветка лучше на 15 п.п. дольше 4 с и с прошлой смены прошло достаточно времени.
- Частоты в спектакле: развилка раз в 1,5–2 мин, не чаще раза в минуту; окно сравнения 60–80 с; окно решения режиссёра 5–10 с; сцена 8–10 мин, 4–6 развилок.
  В симуляции время сжато примерно в 5 раз (константы в начале `src/model.js`).

## Структура
- `src/head.html` шрифты и все стили.
- `src/body.html` разметка: занавес, пульт (сцена, «Сценарий», «Условия на костюмах», журнал), состав, костюм.
- `src/track.py` разделы «Как это работает» (схема двух циклов и 8 шагов) и «Ритм», создаёт `track.html`.
- `src/model.js` модель клеток, сравнение с базой, развилки, условия на костюмах.
- `src/stage.js` рисование сцены и кадра камеры.
- `src/ui.js` интерфейс пульта, занавес, меню, шаги, отметки на костюме.
- `src/calibrate.js` пересчёт «подписей» сценариев: `node src/calibrate.js sig`, проверка точности `acc`, статистика финалов `run`.
- `src/suit.jpg` фото костюма.
- `src/build.py` сборка.

## Сборка
Нужен Python 3.
```
python3 src/build.py
python3 src/build.py --url https://ИМЯ.github.io/mikromir/   # + QR-код внизу страницы и файл qr.svg (pip install qrcode)
```

## Публикация на GitHub Pages
1. Создать публичный репозиторий `mikromir` на github.com.
2. Загрузить `index.html` в корень (Add file → Upload files → Commit). Папку `src` можно положить рядом.
3. Settings → Pages → Source: Deploy from a branch → Branch: `main`, папка `/ (root)` → Save.
4. Через 1–2 минуты сайт откроется по адресу `https://ИМЯ.github.io/mikromir/`.
5. QR-код на этот адрес: `python3 src/build.py --url https://ИМЯ.github.io/mikromir/` → файл `qr.svg` для постера.
